# DS Daily - NeetCode 150

This repository contains C++ solutions for daily data structure and algorithm practice, focused mainly on NeetCode 150-style problems.

The goal is to keep solutions organized by topic so it is easier to review, revise, and improve problem-solving patterns.

## Folder Structure

- `array/` - array, frequency, prefix/suffix, and related problems
- `strings/` - string manipulation, hashing, and encoding/decoding problems
- `sliding-window/` - sliding window and contiguous subarray problems
- `backtracking/` - recursion and backtracking-based problems
- `misc/` - additional practice and daily challenge problems
- `graph/` - graph-related problems and future additions
- `hashing/` - hash map and set-based implementations
- `math/` - number theory and math-based solutions
- `tree/` - tree and binary tree problems

## Purpose

- Practice coding daily
- Improve problem-solving speed
- Build strong fundamentals in C++
- Keep solutions categorized for easier review

## Example usage

Compile any file with:

```bash
g++ array/twoSum.cpp -o twoSum
./twoSum
```

## Notes

This repo is intended for learning, revision, and interview preparation. The folder layout helps recruiters, reviewers, or collaborators quickly understand the project focus.
